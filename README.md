다현이 10분 단어 실험실

사용 방법
1. index.html과 data 폴더를 같은 위치에 둡니다.
2. GitHub 저장소에 업로드합니다.
3. GitHub Pages를 켜면 웹앱으로 실행됩니다.

주요 기능
- Word Master BASIC Day 08 JSON 데이터 불러오기
- 하루 10분 미션 자동 구성
- 뜻, 예문 괄호, 파생어/반의어, 철자 테스트
- 정답/오답/유형별 약점 localStorage 자동 저장
- 완전마스터 판정
- 매일 실력점수 및 누적 성장 표시
- 틀린 내용 반복 추천
- 사용자 지정 괄호 문제 저장
- 약점 시험지 TXT 다운로드
- 진도 JSON 내보내기/불러오기

주의
교재 기반 데이터는 개인 학습용으로 사용하세요.
