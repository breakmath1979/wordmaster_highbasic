다현이 Word Master AI 10분 완전마스터

실행 방법
1. index.html을 더블클릭하면 바로 실행됩니다.
2. GitHub Pages에는 index.html 하나만 올려도 됩니다.
3. 진도는 브라우저 localStorage에 저장됩니다.

주요 기능
- 10분 AI 미션
- 오답 5분 압축 복습
- 뜻, 뜻->영어, 예문 괄호, 파생어, 반의어, 품사, 철자 문제
- 사용자 지정 괄호 문제
- 매일 실력 상승 점수
- 완전마스터 판정
- 약점 시험지 TXT 생성
- ChatGPT 고급훈련 프롬프트 생성
